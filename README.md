# Sistema de gestión de canchas deportivas


## Descripción

Aplicación web desarrollada con Flask para la gestión interna de canchas deportivas y reservas. Permite al administrador controlar disponibilidad, registrar reservas y evitar conflictos de horario.

## Funcionalidades

* Gestión de canchas (CRUD)
* Gestión de reservas (CRUD)
* Autenticación de administrador
* Validación básica de disponibilidad por horario
* Cálculo automático de precios

## Tecnologías

* Python
* Flask
* SQLAlchemy
* SQLite
* Bootstrap

## Instalación

```bash
git clone https://github.com/MauricioMedelMoya/SistemaGestionCanchas.git
cd arriendo-canchas
pip install -r requirements.txt
python app.py
```
