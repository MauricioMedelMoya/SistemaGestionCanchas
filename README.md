# Flask CRUD de ejemplo

Aplicación CRUD simple con Flask, SQLite, SQLAlchemy y Bootstrap.

## Requisitos
- Python 3.10+

## Instalación

```bash
python -m venv venv
```

### Windows
```bash
venv\Scripts\activate
```

### Linux / Mac
```bash
source venv/bin/activate
```

Instalar dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar:

```bash
python app.py
```

Abrir en el navegador:

```text
http://127.0.0.1:5000
```
